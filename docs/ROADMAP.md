## 9. Вне первой версии (по ТЗ)

### 9.1 AI-примерка — после релиза

Решение владельца 03.11.2026: продакшен запускается без AI-примерки. Фото тела, скорее всего, относятся к биометрии и должны храниться и обрабатываться в Узбекистане. В prod примерка выключается переключателем (тред AI-примерки). Каталог, корзина, избранное, заказы и кабинеты работают без неё. Кнопка «В примерочную» и раздел примерочной скрываются вместе с выключателем.

Чтобы включить примерку, нужно одно из двух:
- собственный GPU-сервер с моделью примерки в Узбекистане, хранилище биометрии там же;
- письменное заключение юриста, что передача фото во внешний AI-сервис (например, Gemini) допустима, и согласие клиента в нужной форме.

После этого: включить переключатель, прогнать e2e-сценарий примерки (он уже есть и проходит на mock-провайдере), нагрузочный сценарий `tests/load/tryon-and-auth.js`.

## 10. Открытые вопросы к владельцу (раздел 20 ТЗ)

Решения по умолчанию, принятые для продолжения работы, — их можно поменять:

| Вопрос | Принято по умолчанию |
|---|---|
| Слои одежды | один товар на зону манекена |
| Параметры тела | рост, вес, обхват груди, талии, бёдер (все необязательные) |
| Оплата заказа | при получении (наличные/карта курьеру); онлайн-оплата заказа — следующий этап |
| Валюта | UZS, цены хранятся в тийинах |
| Excel-импорт | столбцы: `sku, title, description, category, brand, price, in_stock`; фото — по артикулу в имени файла |
| Модерация | админ только скрывает/блокирует товар с причиной, магазин исправляет сам |
| Хранение фото тела и результатов | первый релиз без AI-примерки (решение владельца 03.11.2026), см. раздел 9.1 |

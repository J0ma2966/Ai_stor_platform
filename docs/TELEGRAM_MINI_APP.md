# Магазин в Telegram (Mini App)

Покупатель открывает магазин прямо в Telegram, кнопкой в нашем боте (тот же бот, через который
идёт вход и уведомления магазинам). Отдельное приложение для iPhone не нужно.

## Ссылка

`https://shop.optolink.uz/` (для узбекского языка — `https://shop.optolink.uz/uz`).

## Как подключить в @BotFather

1. `/mybots` → выбрать бота магазина (не бота «Платформы для заказов»).
2. **Bot Settings → Menu Button → Configure menu button**: отправить ссылку, затем название кнопки,
   например `Магазин`. Кнопка появится слева от поля ввода в чате с ботом.
3. По желанию: **Bot Settings → Configure Mini App → Enable Mini App**, та же ссылка. Тогда в профиле
   бота появится кнопка «Открыть», а магазин можно открыть ссылкой `https://t.me/<бот>?startapp`.

Ничего на сервере менять не нужно, кроме обычного `ai-store update` после выхода этой версии.

## Что делает сайт внутри Telegram

- Телефонный вид как в Android-приложении: нижняя панель «Главная, Каталог, Корзина, Заказы,
  Профиль» (она есть и в обычном мобильном браузере), без подвала сайта.
- Скрипт `telegram-web-app.js` грузится только внутри Telegram (`web/src/lib/telegram.ts`).
- Кнопка «Назад» Telegram на всех экранах, кроме вкладок; цвет шапки Telegram — как фон сайта;
  тема «как в системе» берётся из Telegram; свайп вниз при прокрутке не закрывает магазин.
- Автовход по данным Telegram, если человек уже входил через бота (docs/AUTH.md).
- CSP `frame-ancestors https://web.telegram.org`: веб-версия Telegram открывает Mini App во фрейме,
  приложения Telegram для телефона и компьютера — нет.

## Проверка без Telegram

Откройте сайт с `#tgWebAppData=…` в адресе: сайт включит режим Mini App (флаг в sessionStorage
и cookie `tgapp`). Подписанные данные для теста: `auth.SignTelegramInitData` в Go.

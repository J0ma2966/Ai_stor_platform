# Тестовые данные (убраны перед запуском)

До 8 ноября 2026 команда `api demo-data` создавала 4 тестовых магазина (`demo-denim-lab`,
`demo-atlas-moda`, `demo-street-code`, `demo-gentleman`) и 37 товаров с фото. Перед запуском
для тестовых клиентов данные, фото и команда загрузки удалены из программы.

Осталось только удаление: если тестовые магазины уже лежат в базе, уберите их.

```powershell
.\scripts\dev.ps1 demo remove                               # локально (Windows)
make demo-remove                                             # локально (Linux/macOS)
docker compose exec api /api demo-data remove --allow-prod   # на сервере (APP_ENV=prod)
```

Магазины удаляются вместе с товарами, учётными записями и файлами. Если по тестовому магазину
уже были заказы, он не удаляется, а архивируется и пропадает с витрины. Повторный запуск безопасен.

Вернуть набор можно из истории git (коммит до удаления, пакет `backend/internal/demoseed`).
